# コントソ株式会社 在宅勤務ガイドライン

制定：2023年10月1日　改定：2026年4月1日　所管：人事部

## 1. 対象者
入社後3か月を経過した正社員および契約社員。派遣社員は派遣元との契約条件による。

## 2. 在宅勤務の上限日数
- 原則として**週3日まで**在宅勤務を可とする。
- 育児・介護等の事情がある場合は、所属長の承認により週5日まで拡大できる。
- 新入社員は入社後6か月間、週2日までとする。

## 3. 申請方法
前週の金曜日17:00までに、勤怠システムで翌週分の在宅勤務予定を登録し、所属長の承認を得る。当日の急な変更は、始業時刻までに所属長へチャットで連絡する。

## 4. 勤務時間
- 所定労働時間は出社時と同じ（9:00〜17:30、休憩1時間）。
- 始業・終業時に勤怠システムで打刻する。
- 中抜け（私用での一時離席）は1日2時間まで認め、勤怠システムに記録する。

## 5. 作業環境
- 会社支給PCを使用し、VPN接続のうえ業務を行う（詳細は情報システム利用手順書 第3章を参照）。
- Web会議では背景をぼかすか、会社指定の背景画像を使用する。
- 家族等の第三者が画面を閲覧できない環境で作業する。

## 6. 費用補助
在宅勤務手当として月額3,000円を支給する（月に1日以上在宅勤務を行った場合）。通信費・光熱費の個別精算は行わない。
