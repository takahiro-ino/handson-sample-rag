# コントソ株式会社 情報システム利用手順書

版数：第4版　発行日：2026年3月15日　所管：情報システム部

## 第1章 はじめに
本手順書は、社員が会社支給のPC、社内ネットワーク、クラウドサービスを利用する際の手順と遵守事項を定める。

## 第2章 アカウントとパスワード
1. 社員アカウントは入社時に情報システム部が発行する。
2. パスワードは12文字以上で、英大文字・小文字・数字・記号のうち3種類以上を含めること。
3. パスワードの有効期限は180日とし、期限の14日前からサインイン時に変更を促す通知が表示される。
4. 多要素認証（MFA）は全社員必須である。Microsoft Authenticator アプリを使用すること。

## 第3章 PC利用時の注意事項
本章の内容は特に重要であるため、全社員が年1回の情報セキュリティ研修で確認すること。

1. **離席時は必ず画面ロック**（Windows キー + L）を行うこと。10分間操作がない場合は自動的にロックされる。
2. **USBメモリ等の外部記憶媒体の利用は原則禁止**とする。業務上必要な場合は、情報システム部に申請し、暗号化対応の会社貸与品のみ使用できる。
3. **私物PCやスマートフォンから社内システムへ接続してはならない**。例外は、情報システム部が承認したモバイルデバイス管理（MDM）登録済みの端末のみ。
4. **ソフトウェアのインストールは情報システム部の承認制**とする。承認済みソフトウェアは社内ポータルの「ソフトウェアカタログ」から入手できる。
5. **不審なメールの添付ファイルやリンクは開かない**。不審なメールを受信した場合は、開かずに「不審メール報告」ボタンで報告すること。
6. **社外で業務を行う場合は、VPN接続を必須**とする。公衆Wi-Fi利用時はVPNを接続するまで業務システムにアクセスしないこと。
7. **PCの紛失・盗難は、気づいた時点で直ちに**情報システム部ヘルプデスク（内線 4100）へ連絡すること。夜間・休日は緊急連絡先（070-XXXX-4100）へ連絡する。

## 第4章 クラウドサービスの利用
1. 会社が契約する Microsoft 365 以外のクラウドストレージ（個人向けサービス等）に業務データを保存してはならない。
2. 社外とのファイル共有は、SharePoint または OneDrive の「特定のユーザー」共有を使用し、「リンクを知っている全員」での共有は禁止する。
3. 生成AIサービスの業務利用は、会社が承認したサービス（Microsoft 365 Copilot、社内AIアシスタント）に限る。承認外のサービスへ社内情報を入力してはならない。
